# 📌 CHANGELOG — Lotto Combo Analyzer

All notable changes to this project are documented here.

## [v1.0] — Initial release

🗓️ Date: 2025-10-26

🎯 Overview:
This version establishes the foundational structure and functionality of the Lotto Combo Analyzer project. It includes full data analysis, modeling, prediction, simulation, and association rule mining for lottery number combinations.

🧩 Modules and Features:

1. **Data Preprocessing** (`src/preprocessing.py`)
   - Load and clean historical lottery data from CSV
   - Extract and sort 6-number combinations
   - Prepare unique combination history set

2. **Statistical Analysis** (`src/analysis.py`)
   - Frequency analysis of drawn numbers
   - Sum distribution and descriptive statistics
   - Differential analysis between draws
   - Change classification (up/down/same)

3. **Clustering** (`src/clustering.py`)
   - KMeans clustering of combinations
   - Elbow method for optimal cluster count
   - Cluster distribution visualization

4. **Sequence Preparation** (`src/preprocessing.py`)
   - Transform combinations into sequences
   - Filter out-of-range values
   - One-hot encode labels for classification

5. **LSTM Modeling** (`src/modeling.py`)
   - Build and train LSTM model
   - Hyperparameter tuning with Optuna
   - Cross-validation with K-Fold
   - Metrics: MAE, MSE, RMSE, R², Log Loss, Top-k Accuracy, MAPE

6. **Model Comparison** (`src/comparison.py`)
   - Train Random Forest and XGBoost classifiers
   - Compare performance with LSTM
   - Evaluate accuracy and log loss

7. **Group-Level Evaluation** (`src/evaluation.py`)
   - Compare predicted vs. actual 6-number sets
   - Calculate exact and partial match rates
   - Report accuracy by group

8. **Multiple Simulations** (`src/simulation.py`)
   - Generate multiple unique combinations
   - Filter out historical duplicates
   - Display top simulated predictions

9. **Association Rules (Apriori)** (`src/association.py`)
   - Convert draws into transactions
   - Apply Apriori to find frequent itemsets
   - Generate rules with support, confidence, and lift
   - Visualize lift distribution

10. **Personalized Forecast** (`notebooks/Lotto_Combo_Analyzer.ipynb`)
    - Allow user to input a draw index
    - Generate a unique prediction based on that seed
    - Ensure prediction is not repeated

🛠 Improvements Implemented:

• Logging system for traceability (`logs/run.log`)  
• Top-k Accuracy and MAPE metrics included (`src/modeling.py`)  
• Clear separation between analysis and prediction in notebook (`notebooks/Lotto_Combo_Analyzer.ipynb`)  
• Shared helper functions grouped in `src/utils.py`  
• `.gitignore` excludes logs, results, models, and temp files  
• `README.txt` rewritten with full module breakdown and dataset format
